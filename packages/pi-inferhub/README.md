# [@deathbeam/pi-inferhub](https://www.npmjs.com/package/@deathbeam/pi-inferhub)

InferHub provider with a live model catalog.
Set `INFERHUB_API_KEY`.

## Installation

```sh
# Choose one:
pi install npm:@deathbeam/pi-inferhub            # this package
pi install git:github.com/deathbeam/pi-packages  # all five packages
```

## Development

From this package directory:

```sh
npm install
npm test
pi install .
```
