# [@deathbeam/pi-inferhub](https://www.npmjs.com/package/@deathbeam/pi-inferhub)

InferHub provider with a live model catalog.
Set `INFERHUB_API_KEY`.

## Installation

```sh
# Choose one:
pi install npm:@deathbeam/pi-inferhub            # this package
pi install git:github.com/deathbeam/pi-packages  # all my packages
```

## Development

From the repo root:

```sh
npm install
npm test -- packages/pi-inferhub
pi install ./packages/pi-inferhub
```
