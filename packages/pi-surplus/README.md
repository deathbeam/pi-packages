# [@deathbeam/pi-surplus](https://www.npmjs.com/package/@deathbeam/pi-surplus)

Surplus Intelligence provider with a live model catalog.
Set `SURPLUS_API_KEY`.

## Installation

```sh
# Choose one:
pi install npm:@deathbeam/pi-surplus             # this package
pi install git:github.com/deathbeam/pi-packages  # all my packages
```

## Development

From this package directory:

```sh
npm install
npm test
pi install .
```
