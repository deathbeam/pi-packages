# [@deathbeam/pi-mistral](https://www.npmjs.com/package/@deathbeam/pi-mistral)

Mistral models through the built-in `mistral` provider.
Set `MISTRAL_API_KEY`.

## Installation

```sh
# Choose one:
pi install npm:@deathbeam/pi-mistral             # this package
pi install git:github.com/deathbeam/pi-packages  # all my packages
```

## Development

From the repo root:

```sh
npm install
npm test -- packages/pi-mistral
pi install ./packages/pi-mistral
```
