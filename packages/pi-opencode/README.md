# [@deathbeam/pi-opencode](https://www.npmjs.com/package/@deathbeam/pi-opencode)

OpenCode models through the built-in `opencode` provider.
Set `OPENCODE_API_KEY`.

## Installation

```sh
# Choose one:
pi install npm:@deathbeam/pi-opencode            # this package
pi install git:github.com/deathbeam/pi-packages  # all my packages
```

## Development

From the repo root:

```sh
npm install
npm test -- packages/pi-opencode
pi install ./packages/pi-opencode
```
