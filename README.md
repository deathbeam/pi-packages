# Pi packages

- [@deathbeam/pi-archive](packages/pi-archive) - Search past pi conversations.
- [@deathbeam/pi-combos](packages/pi-combos) - One `combo/<name>` model that falls back to the next model when one fails.
- [@deathbeam/pi-context](packages/pi-context) - Smaller context: RTK command rewriting, stale tool-result pruning, and a separate compaction model.
- [@deathbeam/pi-delegate](packages/pi-delegate) - Run background subagents and apply their changes.
- [@deathbeam/pi-hashline](packages/pi-hashline) - Hash-anchored read, edit, and grep.
- [@deathbeam/pi-images](packages/pi-images) - Image descriptions for vision-less models, plus an image generation tool.
- [@deathbeam/pi-inferhub](packages/pi-inferhub) - InferHub provider with a live model catalog.
- [@deathbeam/pi-keenable](packages/pi-keenable) - Web search and fetch through the Keenable API.
- [@deathbeam/pi-mistral](packages/pi-mistral) - Mistral models through the built-in `mistral` provider.
- [@deathbeam/pi-opencode](packages/pi-opencode) - OpenCode models through the built-in `opencode` provider.
- [@deathbeam/pi-surplus](packages/pi-surplus) - Surplus Intelligence provider with a live model catalog.
- [@deathbeam/pi-usage](packages/pi-usage) - `/usage` dashboard of token usage and cost per provider, model, and project.
