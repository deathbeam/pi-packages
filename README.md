# Pi packages

- [@deathbeam/pi-archive](packages/pi-archive) - Minimal extension for searching past Pi conversations.
- [@deathbeam/pi-combos](packages/pi-combos) - Minimal extension for model combos that fall back to the next model when one fails.
- [@deathbeam/pi-context](packages/pi-context) - Minimal extension for context-window token economy: RTK rewriting, stale tool-result pruning, and a compaction model override.
- [@deathbeam/pi-delegate](packages/pi-delegate) - Minimal extension for delegating tasks to subagents.
- [@deathbeam/pi-hashline](packages/pi-hashline) - Hash-anchored read, edit, and grep.
- [@deathbeam/pi-images](packages/pi-images) - Minimal extension for image descriptions for vision-less models and an image generation tool.
- [@deathbeam/pi-inferhub](packages/pi-inferhub) - InferHub provider with a live model catalog.
- [@deathbeam/pi-keenable](packages/pi-keenable) - Minimal extension for web search and fetch using Keenable API.
- [@deathbeam/pi-opencode](packages/pi-opencode) - OpenCode Zen free models through the built-in opencode provider.
- [@deathbeam/pi-surplus](packages/pi-surplus) - Surplus Intelligence provider with a live model catalog.
- [@deathbeam/pi-usage](packages/pi-usage) - Minimal extension for token usage and cost per provider, model and project.
